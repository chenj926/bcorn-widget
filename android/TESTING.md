# Android 验证记录与设备验收

## 已实测（2026-10-17）

- 官方 Android SDK Platform 35 + Build Tools 35.0.0、Gradle 8.13 自带 Kotlin 2.0.21，离线编译 Kotlin/R.java、资源链接、D8、zipalign 均通过。
- apksigner verify：APK v2、v3 签名验证通过。
- aapt dump badging：包 `com.acorn.widget`；最低 API 26；目标 API 35；提供 app-widget；没有 uses-permission 条目。
- Node bridge 与静态组件契约测试通过。
- 移动尺寸 Chromium + 真实 Android JavaScript bridge / 合成原生回调集成测试通过：无演示回退、导入预览不写缓存、确认保存、候补渲染、ICS 原生导出路由、清除取消保留数据/确认后清空，无页面错误。不是 Android WebView 或真机验证。
- APK asset 白名单检查：共享 renderer / shared JS 和原生适配器；没有 mock.js、个人课表、course_inputs、缓存或认证信息。
- 常规 Gradle Android 构建受当前环境的 JVM 网络不可达阻塞。`wrapper` 任务在不需要插件的空项目中成功，原始官方 wrapper 文件复制到项目。
- 没有可用 Android 设备 / 模拟器，故未验证 Android 运行时、Vivo 桌面组件大小、系统文件选择器或 TalkBack 实际行为。

## 待在手机上验收

1. 安装测试 APK。首次打开应显示“本地课表”和 Android 暂不支持 ACORN 登录/刷新的说明，不能展示演示课程或宣称已登录。
2. 从“导入 JSON”选一份合成测试文件。看到校验预览后取消，已有缓存保持不变；再次导入并确认才替换。
3. 测试无效 JSON、超过 2 MiB 的文件、不合法日期/时间，现有课表不能被破坏。取消系统文件选择器可继续正常使用。
4. 测试今天、课表、成绩；新增/编辑课程、TBA、候补、重叠课时；重开应用后应保留。无缓存时也应能手动添加。
5. 导出 ICS 和 JSON，选择系统保存目标，取消不得提示成功。导入导出的 JSON 应保留信息；用另一个日历应用人工确认 ICS 的时区/停课日/候补过滤。
6. 桌面长按 → 小组件 → ACORN，添加 5×7（若启动器支持）。拖动至较窄/较矮及横屏尺寸，不能崩溃。候补课程有虚线和文字。TBA 计数明确。TalkBack 能读出课表摘要。
7. 点按桌面组件应打开应用课表；逐课操作在应用中。桌面长按应保留启动器移动/缩放功能。
8. 保存课程后检查所有已添加的小组件同步更新。关闭应用后不应有前台服务、通知、后台联网或周期任务。
9. 在非候补且已有时间的课程详情中打开“系统日历中预览下一次上课（单次）”，确认日期、时区、停课日正确；取消编辑不应声称已保存。候补与 TBA 不显示该操作。
10. 长按应用中的课程后打开 Google / 高德地图，系统让使用者选择应用。任意非白名单 URL 不应打开。
11. 杀掉应用、旋转屏幕、切换前后台后重试导入/导出。若系统在选择文件期间回收进程，允许要求重新操作，不允许声称未完成操作已成功。

此清单未打勾的项目不能称作真机验证通过。

12. 使用合成数据验证“清除本地课表与成绩”：取消应保留数据，确认后应用与所有桌面组件清空；重开仍为空。原始导入文件、已导出文件不能被删除。
